DinoBane update

Member-link repair tool.

This adds an admin-only Repair Member Links button. It restores missing membership and Stripe links for active subscriptions. It does not create charges, create subscriptions, cancel subscriptions, or revoke members.

Download repair update
  1. Unzip the downloaded file.
  2. In GitHub Desktop, open the dinobane-platform repository folder.
  3. Copy the client and server folders from the zip into that repository folder and choose Replace.
  4. If READ-ME-FIRST.txt is still in the repository, delete that file.
  5. In GitHub Desktop, enter Add member link repair, click Commit to main, then Push origin.
  6. When Railway finishes, sign in as admin, open User Management, and click Repair Member Links.
Do not change Stripe keys, products, prices, webhook settings, Railway settings, or Cloudflare settings.
